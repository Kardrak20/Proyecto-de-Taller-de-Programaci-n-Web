PN-01: Gestión de Pasajes y Embarque

Empresa de Transportes

← Volver al inicio

Objetivo

Permitir que los clientes puedan comprar pasajes online y que los vendedores puedan realizar la venta de boletos y verificación de identidad antes del embarque.

Entrada

  • Datos del cliente
  • Destino
  • Fecha del viaje
  • Viaje seleccionado
  • Asiento seleccionado

Descripción del proceso

  1. El cliente consulta los destinos y horarios disponibles.
  2. Selecciona el viaje.
  3. El sistema muestra los asientos disponibles.
  4. El cliente selecciona un asiento y registra sus datos.
  5. El cliente realiza la compra online.
  6. El sistema confirma la venta y genera el pasaje.
  7. En caso de una venta presencial, el vendedor registra la venta en el sistema.

Salida

  • Pasaje registrado
  • Asiento ocupado
  • Confirmación de compra
  • Historial de viaje actualizado
  • Información adicional para el viaje

Actores

Cliente Vendedor Administrador

Reglas de Negocio

Regla ¿Por qué es una regla de negocio?
No se puede vender un asiento que ya se encuentre ocupado. Evita que un mismo asiento sea vendido a dos clientes.
Todo pasaje debe estar asociado a un viaje, fecha, asiento y cliente. Permite identificar correctamente cada venta y pasajero.
El precio del pasaje debe corresponder a la tarifa establecida para la ruta seleccionada. Evita cobros incorrectos y garantiza el cumplimiento de las tarifas.
Una vez confirmada la venta, el asiento debe cambiar automáticamente a estado "ocupado". Mantiene actualizada la disponibilidad de asientos.
Un pasaje solo puede venderse para un viaje que se encuentre activo y disponible. Evita registrar ventas para viajes cancelados, suspendidos o no programados.
